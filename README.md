# -Data-Transformation-and-Data-Modeling
Sales data analysis project using Power BI and Power Query to clean, transform, merge, and model order, order detail, and sales target datasets for profitability, sales performance, and target analysis.
Power BI Sales Data Analysis & Data Modeling

Project Overview

This project focuses on preparing, transforming, and modeling sales data using Microsoft Power BI. The objective is to organize multiple datasets, improve data quality, create meaningful summary tables, and establish relationships that support sales and profitability analysis.

Data Preparation & Transformation

Imported and worked with the List of Orders, Order Details, and Sales Target datasets.

Applied data-cleaning techniques, including date conversion, text formatting, and data type standardization.

Reviewed data quality to identify missing values, errors, and potential duplicates.

Merged order-related datasets using the Order ID field.

Created additional queries to support aggregation and analysis.

Data Modeling & Analysis

Prepared relationships between order records and order details using Order ID.

Established the planned category-based relationship between order details and sales targets.

Created summary-table queries to support:

Order count by Order ID.

Average profit by Category.

Total sales amount by Sub-Category.

Sales targets aggregated by Month.
